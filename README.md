# BRONISLAVIK Role Play

3D-симулятор жизни в городе **Нижний Гопинск**, где платно всё: шаурма, туалет, интернет и даже воздух.
Игра целиком в одном файле `index.html` — без установки, работает в браузере на компьютере и телефоне.

## Как запустить

Открой `index.html` в браузере (Chrome, Safari, Firefox, Edge). Нужен интернет: подгружаются Three.js и шрифты.

## Что есть в игре

- Город 7×7 кварталов, область с деревнями, посёлками городского типа, полями, лесами и набережной Волги
- Четыре области, в каждой — свой аэропорт; можно летать пассажиром или работать пилотом
- Любая профессия: машинист метро, таксист, полицейский, врач скорой, ремонтник, нотариус, бандит и другие
- Кольцевое метро с 8 станциями, автобусы, служебный автобус для экипажей, такси с вызовом через телефон
- Отели, гостиница «Уют», съёмные и собственные квартиры, ипотека
- Машины, угоны, погони полиции, разрушаемые машины, оружейный магазин
- Времена года, погода, смена дня и ночи, живой вид из окон
- Телефон с приложениями, промокоды в главном меню

## Управление

| Клавиша | Действие |
|---|---|
| W A S D / стрелки | ходить, рулить |
| Shift | бег |
| E | действие |
| F | сесть в машину / угнать / выйти |
| P | телефон |
| C | сменить камеру |
| Q | достать / сменить оружие |
| ЛКМ / Пробел | выстрел |
| R | перезарядка |
| Esc / ☰ | пауза и выход в главное меню |

На телефоне — джойстик слева (коснись в любом месте левой половины экрана) и кнопки справа.
